# Football Idler

A pixel art American football themed idler/auto battler game built with Godot Engine and GDScript.

## Game Concept

An incremental/idle game combined with auto-battler mechanics featuring American football. Players manage their team, recruit players, and watch battles unfold automatically while gaining resources and upgrades.

## Project Structure

```
.
├── scenes/           # Godot scene files (.tscn)
├── scripts/          # GDScript files (.gd)
├── assets/           # Pixel art, sprites, and audio
│   ├── sprites/      # Character and object sprites
│   ├── backgrounds/  # Level and UI backgrounds
│   └── audio/        # Sound effects and music
├── ui/               # UI scenes and scripts
├── entities/         # Player, enemy, and NPC entities
└── systems/          # Core game systems (battle, progression, etc)
```

## Development

- **Engine**: Godot 4.x
- **Language**: GDScript
- **Art Style**: Pixel Art
- **Target Platform**: Desktop (expandable to web/mobile)
